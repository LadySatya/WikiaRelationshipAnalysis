# Archive

Point-in-time reports from November 2025. They are kept for history only and are **not accurate descriptions of the current code**: they refer to modules that have since been removed (`CharacterExtractor`, `ProfileBuilder`, the relationship verification tools), logging helpers that never existed (`log_phase_start`, `log_progress`), and test counts and coverage figures that are out of date.

| File | What it was |
|---|---|
| `LOGGING_MIGRATION.md` | Guide for moving modules to the per-module logging system (migration complete) |
| `LOGGING_IMPLEMENTATION_SUMMARY.md` | Report on building the logging system |
| `LOGGING_MIGRATION_COMPLETE.md` | Report on finishing the logging migration |
| `TEST_IMPROVEMENTS_SUMMARY.md` | Report on a test cleanup (572 -> 682 tests) |
| `TEST_QUALITY_REVIEW.md` | Review of tests for tools that no longer exist |
